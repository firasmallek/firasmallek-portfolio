## ✨ The Experience

This isn't designed to be a traditional portfolio.

The website uses **motion, interaction, transitions, and 3D elements** to turn browsing through my work into an experience.

Every section was designed with the idea that **how information is presented can be just as important as the information itself.**

## 🤖 AI-Assisted Development

AI played a major role in the development of this project.

Rather than treating AI as a one-click website generator, I used it as part of an **iterative engineering workflow**.

### My workflow

**💡 Idea → 🧠 Prompt → ⚙️ Generate → 🔍 Evaluate → 🐛 Debug → 🔄 Iterate → ✨ Refine**

I used AI coding tools to help with:

* Exploring technical approaches
* Turning ideas into implementations
* Writing and improving code
* Designing complex interactions
* Debugging unexpected behavior
* Refactoring and optimizing code
* Exploring animation techniques
* Rapidly testing different ideas

The important part wasn't simply generating code — it was **knowing what to ask for, providing the right context, evaluating the output, identifying problems, and iterating until it matched the intended result.**

This project helped me develop practical skills in **prompt engineering, AI-assisted programming, debugging, code evaluation, and rapid iteration.**

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/firasmallek/firasmallek-portfolio.git
```

Open the project:

```bash
cd firasmallek-portfolio
```

Then open `index.html` in your browser, or use a local development server.
